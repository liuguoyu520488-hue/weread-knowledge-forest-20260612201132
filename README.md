# 微信读书“知识森林”游戏化改造网页原型

## 项目简介

这是一个基于微信读书的游戏化改造方案网页原型。它通过“一本书一棵树”的方式，把阅读进度、阅读类型和阅读思考可视化，让阅读行为变得更容易被看见。

## 核心设计

- 一本书对应一棵树。
- 阅读进度决定树木成长阶段。
- 不同类型书籍对应不同树种。
- 书评、评论和阅读想法生成黄金叶片。
- 长时间未阅读的书树进入休眠状态。

## 如何运行

直接打开 `index.html` 即可查看网页原型。

如果需要让同一 Wi-Fi 下的其他电脑或手机打开，双击 `start-share.bat`，然后在其他设备的浏览器中输入窗口里显示的地址，例如：

`http://你的电脑IP:8765/index.html`

展示期间请保持 `start-share.bat` 的窗口打开。关闭窗口后，其他设备就无法继续访问。

## 页面交互

- 点击任意书树卡片，可以查看书名、类型、进度、成长阶段、黄金叶片和阅读状态。
- 使用分类按钮，可以筛选文学、历史、科幻、心理学、经济管理和修仙类书树。
- 在详情弹窗中点击“继续阅读 5%”，书树会更新阅读进度和成长阶段。
- 在详情弹窗中点击“写下想法，获得黄金叶”，对应书树会增加一片黄金叶。
- 休眠中的书树会以更淡、更柔和的状态展示，并提示重新阅读后恢复生长。
